## What was built
- `apps/api/src/queue/queue.constants.ts` — queue name enums + job data interfaces
- `apps/api/src/queue/queue.module.ts` — BullModule.registerQueue for 3 queues
- `apps/api/src/queue/processors/campaign-dispatch.processor.ts`
  - Loads campaign, resolves contacts, applies frequency cap and quiet hours delay
  - Batches 100 contacts → inserts delivery rows → enqueues per-delivery send jobs
  - concurrency: 1 (prevents status race conditions)
- `apps/api/src/queue/processors/email-send.processor.ts`
  - Idempotency guard (checks status !== 'queued' before sending)
  - Calls EmailService.send() → updates delivery status + inserts delivery_event
  - BullMQ options: attempts: 4, backoff: exponential 1s
- `apps/api/src/queue/processors/whatsapp-send.processor.ts`
  - Mirrors email processor pattern
